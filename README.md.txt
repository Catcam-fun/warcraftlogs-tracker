# WarcraftLogs Death Report Generator

A client-side web app for generating death count reports from any World of Warcraft guild's WarcraftLogs.

## Features
- Configure any guild, server, and region
- Merge alt characters into main characters
- Filter by date and log uploaders
- Calculate death rates per boss and overall
- Fully client-side - no backend needed

## Usage
Visit: https://catcam-fun.github.io/wcl-death-reporter/

You'll need your own WarcraftLogs API key (found in User Settings on WarcraftLogs).
